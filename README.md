# কাজী নজরুল ইসলাম হল মসজিদ, বুয়েট — অফিশিয়াল ওয়েবসাইট

বাংলাদেশ প্রকৌশল বিশ্ববিদ্যালয়ের (বুয়েট) কাজী নজরুল ইসলাম হল মসজিদের জামায়াতের সময়সূচী এবং হল মসজিদ লাইব্রেরির বইসমূহের তালিকার ওয়েবসাইট।

## ফাইল স্ট্রাকচার
- `index.html` — সম্পূর্ণ ওয়েবসাইটের কোড (হোম পেজ, জামায়াতের সময়সূচী পেজ, বইয়ের তালিকা ও ক্যাটাগরি ফিল্টার, ডার্ক ও লাইট মোড)।
- `vercel.json` — Vercel ডিপ্লয়মেন্ট কনফিগারেশন।

## GitHub এবং Vercel-এ লঞ্চ করার ধাপসমূহ
১. আপনার GitHub অ্যাকাউন্টে লগইন করে একটি নতুন Repository তৈরি করুন (যেমন: `kazi-nazrul-islam-hall-mosque`)।
২. এই ফোল্ডারের `index.html`, `vercel.json` এবং `README.md` ফাইলগুলো আপনার GitHub Repository-তে আপলোড (বা `git push`) করুন।
৩. এরপর [vercel.com](https://vercel.com)-এ গিয়ে **Add New... -> Project** বাটনে ক্লিক করুন।
৪. আপনার GitHub Repository-টি সিলেক্ট করে **Import** করুন এবং **Deploy** বাটনে ক্লিক করুন (Framework Preset হিসেবে `Other` থাকবে)।
৫. কয়েক সেকেন্ডের মধ্যে আপনার ওয়েবসাইটটি লাইভ হয়ে যাবে।
